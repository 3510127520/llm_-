## 第二章 三大高薪方向3年深耕路线图

以下三个方向是**最适合在校生冲击高薪**的路径，从大一到大四及毕业后第一年，直接跟着走。

### 2.1 方向一：大模型应用开发 / Agent开发

**定位**：用LLM解决实际问题，连接模型与业务。

#### 3年分阶段路线图

- **入门期（第1-5个月，大二上）**：熟练Python，掌握提示工程，能调API搭建简单问答机器人。
- **进阶期（第6-14个月，大二下～大三上）**：精通RAG全流程，会用LangChain/LlamaIndex，开发Agent工具调用，能做微调（LoRA），积累2个完整项目。
- **精通期（第15-30个月，大三下～大四/研一）**：生产级系统设计，多Agents协作，推理加速（vLLM/量化），具备架构能力，有大厂核心部门实习产出。

#### 必学技术栈（框架级分类）

- **编程语言**：Python（类型注解、异步asyncio、pydantic）
- **LLM调用**：OpenAI SDK、LangChain、LlamaIndex、Semantic Kernel
- **向量/检索**：text-embedding-3 / BGE-M3、Milvus/Qdrant/Chroma、RAG Fusion、重排序（Cohere/BGE-Reranker）
- **Agent框架**：ReAct、Function Calling、AutoGen / CrewAI
- **模型微调**：LoRA/QLoRA（PEFT）、DeepSpeed ZeRO、HuggingFace Trainer
- **部署工具**：FastAPI、Docker、Gradio/Streamlit、vLLM/TGI

#### 最优学习路径（先后顺序）

1. 《ChatGPT Prompt Engineering for Developers》课程（吴恩达）
2. 读《LLM Engineer's Handbook》做配套项目
3. 深入 LangChain/LlamaIndex 官方文档，手写复杂 RAG Pipeline
4. 用 LoRA 微调一个7B模型解决特定任务
5. 用 FastAPI + Docker 将其部署到云服务器，压测并优化
6. 构建一个带记忆和工具的多Agent系统

#### 推荐资源清单

- **课程**：吴恩达《Building Systems with the ChatGPT API》 / 《LangChain for LLM App Dev》 (DeepLearning.AI)；《LLMOps》（YouTube频道）
- **书籍**：《大规模语言模型：从理论到实践》、《LangChain入门与实战》
- **必读论文**：Attention Is All You Need、RAG paper (2005.11401)、ReAct (2210.03629)、Self-Refine
- **认证**：不用专门考，GitHub项目星数比认证值钱

#### 实习节点建议

- **第一份实习（大三上学期）**：中小厂AI应用开发/全栈实习，要求独立部署过demo。
- **冲刺大厂（大三下学期/暑假）**：投递“AI产品研发”“大模型应用”岗位，简历上必须有量化结果的项目（如准确率92%）。
- **转正或秋招（大四上）**：手握高完成度Agent项目，面试直接讲生产环境细节。

### 2.3 方向三：MLOps / AI基础设施工程师

**定位**：让模型训得快、推得稳、成本低，越老越吃香。

#### 3年分阶段路线图

#### 必学技术栈

5. 自建一个模型监控体系，检测推理延迟漂移、数据漂移。

## 第三章 高薪面试亮点级实战项目

### 完整项目：多模态企业知识库智能体「KnowBot」

**选题价值**：企业内部文档庞杂，新人找政策、找流程难。用RAG+Agent实现秒级精准问答与自动工单。有直接商业落地场景，面试官一看就懂。

#### 技术全链路
文本&图像解析 → 智能分块&嵌入 → 混合检索+重排序 → Agent调度 → 微调 → 部署监控

### 3.1 从0到1全流程实践步骤

> 每步均标注工具/框架，关键逻辑用伪代码呈现。

**第1步：环境与数据**
- 准备2000+企业PDF/Word/表格，及截图。
- 工具：Python 3.11、PyPDF2、Unstructured、PaddleOCR

**第2步：文档解析与清洗**
```python
# 伪代码：读取文档并提取文本+表格+图片描述
from unstructured.partition.auto import partition
elements = partition(filename="policy.pdf", strategy="hi_res")
docs = element_to_document(elements)
```
- 对图片使用BLIP/BLIP-2生成描述文本，存入原始文档。

**第3步：智能分块与元数据**
```python
from langchain.text_splitter import RecursiveCharacterTextSplitter
splitter = RecursiveCharacterTextSplitter(chunk_size=512, chunk_overlap=50,
    separators=["\n\n", "\n", "。", " "])
chunks = splitter.split_documents(docs)
# 为每个块增加页码、来源等元数据
```

**第4步：向量化与混合存储**
- 嵌入模型：`BAAI/bge-m3`，用HuggingFace加载
- 向量数据库：Milvus Lite（本地）/ Qdrant（生产）
- 同时建立BM25倒排索引（使用`rank_bm25`库）实现稀疏检索。

**第5步：混合检索与重排序**
```python
# 伪代码：融合向量相似度和BM25得分
vector_results = vector_store.similarity_search_with_score(query, k=20)
bm25_results = bm25_index.search(query, k=20)
# RRF (倒数排名融合) 合并
fused = reciprocal_rank_fusion([vector_results, bm25_results])
# 重排序
from FlagEmbedding import FlagReranker
reranker = FlagReranker('BAAI/bge-reranker-v2-m3')
scores = reranker.compute_score([[query, doc] for doc in fused])
final_docs = sorted_by_score(scores)[:5]
```

**第6步：RAG问答与防幻觉**
```python
from langchain.prompts import ChatPromptTemplate
template = """基于下方上下文回答。若不知道，如实说不知道。
上下文：{context}
问题：{question}"""
prompt = ChatPromptTemplate.from_template(template)
# 调用大模型 (Qwen2.5-7B-Chat 或 gpt-4o-mini)
chain = prompt | llm | StrOutputParser()
answer = chain.invoke({"context": merged_text, "question": user_q})
```

**第7步：Agent工具集成**
设计3个工具：查询订单、申请退款、转人工
```python
from langchain.agents import tool
@tool
def check_order(order_id: str) -> str:
    """查询订单状态，输入订单号"""
    # 模拟调API
    return f"订单{order_id}状态：已发货"
```
Agent使用ReAct模式，当用户问“我的订单到哪了”，自动调用工具。

**第8步：针对性微调（体现训练优化）**
- 收集200条人工标注的高质量问答对。
- 用LoRA微调Qwen2.5-7B，降低幻觉，学习工具调用格式。
```python
from peft import LoraConfig, get_peft_model
lora_config = LoraConfig(r=8, lora_alpha=16, target_modules=["q_proj","v_proj"])
model = get_peft_model(base_model, lora_config)
trainer = Trainer(...)  # 使用transformers训练一个epoch
```

**第9步：服务化与部署**
- FastAPI封装，Uvicorn启动，Docker打包。
- 引入Redis缓存常见问题向量结果，异步任务队列Celery处理文档更新。
- 配置Nginx反向代理，限流。

**第10步：监控与性能评估**
- RAGAS评估：忠诚度>0.95，答案相关度>0.90。
- 使用Locust压测，目标QPS 200+，99分位延迟<1.5秒。
- Prometheus + Grafana面板监控请求量、错误率、检索质量。

## 第四章 通用技能包与职业加速器

### 4.2 软技能与个人品牌包装

- **用输出倒逼输入**：每周写技术博客/公众号文章，系列化（如“从零实现RAG”），很快就会有猎头通过关键词找到你。

- **Networking**：混迹Kaggle拿银/金牌，LinkedIn上主动连接大厂技术负责人，附言带上你项目的链接和一行独特见解，回复率超高。
