## 🧩 你问的“怎么拼”——给你看一个例子

假设你现在要写一个“统计所有 txt 文件行数”的小功能，你不需要从头想，你直接从上面的模板里捡：

1. **遍历所有 .txt** → 模板：`for file in Path(".").glob("*.txt"):`
2. **读取文件内容** → 模板：`with open(file, "r", encoding="utf-8") as f: content = f.read()`
3. **统计行数** → 模板：`lines = content.splitlines()`
4. **累加总数** → 模板：`total += len(lines)`

拼在一起就是：

```python
from pathlib import Path

total_lines = 0
for file in Path(".").glob("*.txt"):
    with open(file, "r", encoding="utf-8") as f:
        content = f.read()
        lines = content.splitlines()
        total_lines += len(lines)

print(f"总行数: {total_lines}")
```

**你不需要记住每一行，你只需要记住：**
> “遍历文件 → 读文件 → 统计 → 累加”

然后从模板表里把对应的“砖块”拿出来，拼上去就行。
